## How to install (about 1 minute)

1. **Download** the skill's zip from the table above.
2. Open the **Claude desktop app** on your computer (Mac or Windows).
3. **Drop the zip into the chat** and type: **"Set up this skill for me."**
4. Claude runs the setup itself and renders a short test video to check that everything works.

If something is missing on your computer (for example Python), Claude tells you the one thing to click. You never need to create folders or type commands.

## FAQ

**Do I need to pay for Claude?**
Skills work on every Claude plan, including Free. Turn on **code execution** in Settings → Capabilities first. A full video is a lot of work, though, so on the Free plan you'll probably reach your limit before it finishes. **Pro is the realistic starting point.**

**How many videos can I make per plan?**
It depends on the video's length and on the skill. Start with a short test (60 to 90 seconds) to see how much of your usage it takes.

**Can I use it on my phone?**
No. Use the Claude desktop app on a computer. The skills install tools and render video on your machine.

**Which voice should I use?**
Every skill has a **free voice** built in. For a more professional sound, I use **ElevenLabs**: [try it here](https://try.elevenlabs.io/6gtup6uyhxs3). Export your voiceover as an MP3 and give it to Claude.

**Can I use another language?**
Yes, with a voiceover from ElevenLabs in your language. The free built-in voice is English.

**Is the footage and music safe to use?**
The skills use public-domain art, NASA images and archive footage, and credit every source. Their music is generated by the skill itself, so it's original. Still, **always check the credits before you upload.** You are responsible for what you publish.

**The skill doesn't work on my laptop. What should I do?**
Tell Claude exactly what happened ("the setup failed with this error…"). It can usually fix it on the spot. Most problems come from an old Python version or from code execution being switched off.
